# About LapTap

**LapTap** is a simple lap counter for parents, supporters and coaches at multi-lap cycling, running and multisport events.

## Why I built LapTap

I'm the parent of a youth triathlete, and at many races part of my job is helping keep count of laps. It's harder than it sounds. You're watching, cheering and following the race, and it's surprisingly easy to lose count. We've learnt the hard way: on more than one occasion, my child has been disqualified for completing the wrong number of laps.

LapTap solves that problem. Each time your athlete passes, tap the screen and LapTap keeps count of the laps and time splits.

## Built for race day

LapTap is designed to need as little attention as possible, with large buttons, a high-contrast outdoor display for sunny days, clear laps remaining, a simple Undo button if you tapped too soon, and a Share Results button.

It works for cycle circuits, velodromes, cyclocross, cross-country, running, duathlons, triathlons and other multi-lap events.

## How to use LapTap

1. **Set the laps** for each part of the race.
2. **Tap** each time your athlete passes.
3. LapTap **counts down the laps remaining** and changes discipline when needed.
4. Use **Undo** for mistakes and **Reset** for a new race.
